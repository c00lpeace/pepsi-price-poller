# 펩시 제로 라임 15분 가격 폴러

쿠팡 상품 페이지를 15분마다 확인해 가격을 기록하는 작은 크롤러입니다.
브라우저를 띄우지 않고 HTTP GET 1회 + HTML 안의 JSON-LD 파싱으로 가격을 가져옵니다.
토큰(에이전트 실행 비용)이 들지 않습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `poll.py` | 가격 수집 스크립트 (표준 라이브러리만 사용) |
| `notify.py` | 특가 감지 시 ntfy.sh 푸시 발송 (선택) |
| `.github/workflows/poll.yml` | 15분 간격 자동 실행 설정 |
| `prices.jsonl` | 가격 기록 (1줄 = 1회 수집) |
| `alert.json` | 최근 실행의 특가 알림 내역 |

## 배포 순서 (5분)

1. GitHub에서 **새 저장소**를 만듭니다. **Public 권장**입니다.
   (Private 저장소는 Actions 무료 월 2,000분 제한이 있어 하루 96회 실행 시 초과될 수 있습니다. Public은 무제한입니다.)
2. 이 폴더의 모든 파일을 저장소에 푸시합니다. (`.github/` 폴더 포함)
3. 저장소의 **Actions 탭**을 열어 워크플로가 등록됐는지 확인합니다.
   - 스케줄 실행은 **기본 브랜치(main)** 에 파일이 있어야 동작합니다.
   - 바로 테스트하려면 워크플로에서 **Run workflow** 버튼을 누릅니다.
4. 끝. 이후 15분마다 `prices.jsonl`에 가격이 쌓입니다.

## 특가 푸시 알림 받기 (선택)

1. 휴대폰에 **ntfy** 앱을 설치합니다 (무료, 가입 불필요).
2. 앱에서 원하는 토픽명을 구독합니다. 예: `pepsi-alert-abc123` (남과 겹치지 않게 랜덤하게)
3. GitHub 저장소 → **Settings → Secrets and variables → Actions** → **New repository secret**
   - Name: `NTFY_TOPIC`, Value: 위에서 정한 토픽명
4. 이후 특가 감지 시 휴대폰으로 푸시가 옵니다.

## 알림 기준 (poll.py 상단 PRODUCTS에서 조정)

- 100ml당 95원 이하 → 최저가 경신급 특가
- 직전 가격 대비 5% 이상 하락 → 급락
- 품절 / 재입고 상태 변화

## 운영 시 알아둘 점

- 실행 시각은 정확히 보장되지 않습니다. 깃허브 사정에 따라 몇 분씩 밀릴 수 있습니다.
- Public 저장소는 60일간 활동이 없으면 스케줄이 자동 중단됩니다.
  가격 기록이 계속 커밋되므로 사실상 계속 살아있지만, 가끔 Actions 탭에서 확인해 주세요.
- **중요: 쿠팡이 데이터센터 IP를 차단할 수 있습니다.** 테스트 결과 GitHub Actions 같은
  클라우드 서버 IP에서는 403 응답이 돌아올 수 있습니다. 먼저 Actions 탭에서
  **Run workflow**로 수동 실행해 `prices.jsonl`에 정상 기록이 쌓이는지 확인하세요.
  차단된다면 대안은 두 가지입니다: (1) 집 PC에서 실행 (README 하단 로컬 실행 참고,
  일반 가정집 IP는 대부분 정상 동작), (2) 기존의 하루 3회 브라우저 기반 추적을 유지하고
  이 폴러는 보조로 사용.
- 쿠팡 봇 탐지가 간헐적으로 빈 페이지를 반환합니다. 스크립트에 재시도(3회)가 내장돼 있고,
  그래도 실패하면 해당 회차는 `blocked`로 기록됩니다. `blocked`가 연속으로 쌓이면
  Actions 로그를 확인해 주세요.
- 하루 96개 커밋이 쌓입니다. 지저분해 보이면 주기적으로 히스토리를 정리하세요.

## 로컬 테스트

```bash
python3 poll.py          # 가격 수집 1회
NTFY_TOPIC=내토픽 python3 notify.py   # 알림 테스트
```
